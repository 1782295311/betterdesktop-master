# 经典开始菜单布局精细设计：Win7 / Win10 / Win11

> 日期：2026-08-26
> 用途：shell-start-menu 自绘实现的布局规格书
> 说明：以下尺寸以 **96 DPI（100% 缩放）** 为基准，实际渲染按 DPI 缩放。所有颜色/字体/圆角走 IThemeTokens，本文只定义结构、位置、尺寸、交互。

---

## 通用行为（三种布局共有）

| 行为 | 规格 |
|------|------|
| 弹出位置 | 紧贴任务栏开始按钮上方；任务栏在底部时菜单底边距屏幕底边约 48px（任务栏高度），水平左边缘对齐开始按钮左边缘 |
| 多显示器 | 在开始按钮所在显示器弹出 |
| 打开动画 | 从左下角向上渐入 + 轻微缩放（0.98→1.0），150ms |
| 关闭方式 | 点击菜单外部（Deactivated）、按 Esc、按 Win 键、启动程序后 |
| 键盘导航 | 上下箭头移动选中项，回车启动，右键打开上下文菜单，Esc 关闭 |
| 搜索触发 | 菜单打开后直接键入字符即进入搜索（无需点击搜索框） |
| 毛玻璃 | 窗口背景走 IVibrancyService，内容区走 IAppearanceService 主题令牌 |
| 单例 | Hide/Show，不每次 new |

# 一、Windows 7 布局

## 1.1 整体结构

```
┌──────────────────────────────────────────────┐
│ ┌────────────────────┬──────────────────────┐ │
│ │  [固定程序区]       │   [头像]  用户名      │ │
│ │   Internet Exp..   │──────────────────────│ │
│ │   电子邮件         │   文档                │ │
│ │────────────────────│   图片                │ │
│ │  [最近使用程序]     │   音乐                │ │
│ │   程序1            │   游戏                │ │
│ │   程序2            │   计算机              │ │
│ │   程序3            │   控制面板            │ │
│ │   ...（最多9项）    │   设备和打印机        │ │
│ │                    │   默认程序            │ │
│ │                    │   帮助和支持          │ │
│ │────────────────────│──────────────────────│ │
│ │  所有程序 ▶        │   [关机]  ▶           │ │
│ ├────────────────────┴──────────────────────┤ │
│ │ 🔍 搜索程序和文件                          │ │
│ └────────────────────────────────────────────┘ │
└──────────────────────────────────────────────┘
```

- **总宽度**：默认 400px（可拖拽右边框调整，范围 300–800px）
- **总高度**：约 520px（随左栏程序项数自适应，最小 400px）
- **左右栏比例**：约 1:1，中间 1px 分割线（`#D0D0D0` 浅色 / `#3A3A3A` 深色）
- **圆角**：左上角和右上角 6px，左下角和右下角 6px（窗口圆角）
- **内边距**：内容区 2px

## 1.2 左栏（程序区）

### 1.2.1 固定程序区（顶部）
- **位置**：左栏顶部
- **项数**：默认 2 项（Internet Explorer、电子邮件客户端），用户可固定更多
- **每项高度**：28px，图标 16×16px 左侧，文字 12px Segoe UI
- **内边距**：左 8px，文字距图标 8px
- **悬停背景**：浅色 `#E5F1FB` + 1px 边框 `#B8D6ED`；深色 `#2D2D30`
- **分隔线**：固定区与最近使用区之间 1px 线，左右各留 4px 边距
- **右键菜单**：打开、从列表中删除、附到开始菜单（固定）、属性

### 1.2.2 最近使用程序区（中部，MFU）
- **位置**：固定区分隔线下方
- **项数**：最多 9 项，按使用频率排序
- **每项高度**：28px，图标 16×16px，文字 12px
- **数据来源**：IRecentItemsService.GetRecentPrograms(9)
- **动态更新**：程序启动后刷新排序
- **悬停/选中样式**：同固定区
- **右键菜单**：打开、从列表中删除、附到开始菜单、属性、打开文件位置

### 1.2.3 "所有程序"按钮
- **位置**：左栏底部，搜索框上方
- **高度**：28px，占满左栏宽度
- **内容**：文字"所有程序"（12px），右侧 ▶ 箭头（展开前）/ ▼（展开后）
- **悬停背景**：同程序项
- **点击行为**：
  - 展开前：左栏切换为**程序树视图**（树形展开），按钮文字变为"返回"，箭头变为 ◀
  - 展开后：显示开始菜单目录的文件夹层级，文件夹可点击展开/折叠，叶子节点是程序
  - 文件夹项：图标为文件夹图标，右侧 ▶ 表示有子项；点击展开内联子项
  - 程序项：图标+名称，点击启动
  - 超出高度时显示垂直滚动条（宽度 16px）
- **搜索状态**：搜索时"所有程序"按钮隐藏，左栏显示搜索结果

### 1.2.4 搜索框（底部，跨左栏）
- **位置**：左栏最底部
- **宽度**：占满左栏宽度（不含右栏）
- **高度**：30px
- **结构**：左侧放大镜图标（16×16px，距左 8px），右侧输入区
- **提示文字**："搜索程序和文件"（浅色 `#A0A0A0`）
- **边框**：1px `#ABADB3`，聚焦时 `#7198D3`（蓝色）
- **背景**：白色（浅色模式）/ `#2D2D30`（深色模式）
- **输入文字**：12px Segoe UI
- **实时搜索**：输入即搜，防抖 150ms
- **搜索结果视图**（左栏切换）：
  - 按类别分组：程序（Programs）、控制面板（Control Panel）、文档（Documents）、图片、音乐、文件等
  - 每组标题 11px 蓝色 `#0066CC`，如"程序 (3)"
  - 每组最多显示 3 条，点击组标题或底部"查看更多结果"打开完整搜索窗口
  - 每项 28px，图标 16px + 名称 + 高亮匹配文字（蓝色）
  - 顶部最佳匹配项高亮显示（蓝色背景）
  - 按回车启动最佳匹配项

## 1.3 右栏（系统链接区）

### 1.3.1 用户头像 + 用户名（顶部）
- **位置**：右栏顶部
- **高度**：56px
- **头像**：48×48px，左上角距右栏左边缘 12px，距顶 4px，带 1px 白色边框
- **用户名**：12px，位于头像右侧，垂直居中，距头像 10px，粗体
- **点击**：打开用户账户控制面板
- **悬停背景**：同程序项

### 1.3.2 系统链接列表
- **位置**：头像下方，关机按钮上方
- **每项高度**：32px（比左栏项高，因为是主要导航）
- **图标**：24×24px，距左 12px
- **文字**：12px Segoe UI，距图标 10px
- **顺序**（默认，从上到下）：
  1. 个人文件夹（用户名命名）— 打开 `%USERPROFILE%`
  2. 文档 — 打开 Documents 库
  3. 图片 — Pictures 库
  4. 音乐 — Music 库
  5. 游戏 — Games 文件夹
  6. 计算机 — 打开"此电脑"
  7. 控制面板 — 打开控制面板
  8. 设备和打印机 — 打开设备和打印机
  9. 默认程序 — 打开默认程序设置
  10. 帮助和支持 — 打开 Windows 帮助
- **可配置**：用户可在设置中选择显示/隐藏/重命名这些项目
- **悬停背景**：同左栏
- **部分项目有 ▶ 箭头**：如"计算机"右侧有箭头，悬停展开子菜单（磁盘列表）

### 1.3.3 关机按钮区（底部）
- **位置**：右栏最底部
- **高度**：40px，左右各留 8px 边距
- **结构**：左右两部分
  - **左侧主按钮**（占约 70% 宽度）：
    - 高度 30px，圆角 3px
    - 文字：默认"关机"（可配置为其他默认动作），12px 粗体
    - 背景：浅色 `#D7EAF8` + 渐变，悬停 `#B8D6ED`；深色 `#2D5A8C`
    - 左侧关机图标 16×16px
    - 点击：执行默认电源动作（关机）
  - **右侧箭头按钮**（约 30px 宽）：
    - 显示 ▶ 箭头
    - 点击弹出扩展菜单（向上弹出）：
      - 切换用户（Switch user）
      - 注销（Log off）
      - 锁定（Lock）
      - 重新启动（Restart）
      - 睡眠（Sleep）
      - 休眠（Hibernate）
      - 关机（Shut down）
    - 菜单每项 28px，图标+文字
- **数据来源**：IPowerManagementService

## 1.4 交互细节

| 操作 | 行为 |
|------|------|
| 点击程序项 | 启动程序，菜单关闭 |
| 右键程序项 | 上下文菜单（打开/以管理员运行/打开文件位置/附到开始菜单/从列表删除/属性） |
| 悬停程序项 | 显示高亮背景，图标轻微变亮 |
| 按 → 键 | 如果有子菜单（所有程序/计算机），展开子菜单 |
| 按 ← 键 | 从子菜单返回 |
| 拖拽程序项 | 可调整固定程序顺序 |
| 搜索时按 ↑↓ | 在搜索结果中移动 |
| 搜索时按回车 | 启动选中项（默认最佳匹配） |

# 二、Windows 10 布局

## 2.1 整体结构

```
┌──────────────────────────────────────────────────────────┐
│┌──┐┌──────────────────────┬────────────────────────────┐│
││≡ ││ 最近添加              │  生产力                    ││
││  ││  ├ 应用A              │  ┌────┐ ┌────┐ ┌────┐     ││
││👤││  ├ 应用B              │  │磁贴│ │磁贴│ │磁贴│     ││
││  ││ 最常用                │  └────┘ └────┘ └────┘     ││
││📁││  ├ 应用C              │  ┌────┐ ┌──────────┐     ││
││⚙ ││  ├ 应用D              │  │磁贴│ │ 宽磁贴   │     ││
││  ││  A                    │  └────┘ └──────────┘     ││
││⏻ ││  ├ Apple              │  播放和浏览                ││
││  ││  ├ 应用E              │  ┌────┐ ┌────┐ ┌────┐     ││
│└──┘│  ├ ...               │  │磁贴│ │磁贴│ │磁贴│     ││
│    │  B                    │  └────┘ └────┘ └────┘     ││
│    │  ├ 应用F              │                            ││
│    │  ...                  │                            ││
│    │  Z                    │                            ││
│    │  └ 应用Z              │                            ││
│    └──────────────────────┴────────────────────────────┘│
└──────────────────────────────────────────────────────────┘
```

- **总宽度**：默认 640px（窄边栏 48px + 应用列表约 260px + 磁贴区约 332px），可拖拽右边缘调整（最窄 540px，最宽 1000px）
- **总高度**：默认 640px，可拖拽上边缘调整（最小 400px）
- **三栏结构**：
  1. 左侧窄边栏（rail）：48px
  2. 中间应用列表：约 260px（固定，不随窗口宽度变化）
  3. 右侧磁贴区：剩余宽度，至少 300px

## 2.2 左侧窄边栏（Rail）

- **宽度**：48px（折叠）/ 200px（展开，显示文字标签）
- **背景**：浅色 `#F2F2F2` / 深色 `#202020`（与磁贴区略有区分）
- **从上到下**：

| 位置 | 元素 | 尺寸 | 行为 |
|------|------|------|------|
| 顶部（距顶 8px） | 汉堡菜单按钮 ≡ | 36×36px，图标 16px | 点击展开/折叠边栏（展开后显示文字标签） |
| 汉堡下方 | 用户头像 | 32×32px 圆形 | 点击弹出账户菜单（更改账户设置/锁定/注销） |
| 中部偏上 | 文件资源管理器图标 | 36×36px，图标 16px | 打开资源管理器 |
| 中部 | 设置图标 ⚙ | 36×36px | 打开设置 |
| 底部（距底 8px） | 电源图标 ⏻ | 36×36px | 点击弹出电源菜单（睡眠/关机/重启） |

- **展开状态**：边栏展开为 200px，每个图标右侧显示文字标签（"展开"/用户名/"文档"/"设置"/"电源"）
- **悬停**：背景 `#E5E5E5`（浅色）/ `#333333`（深色），圆角 4px
- **汉堡按钮展开后**：≡ 仍在左上角，点击收回
- **可配置**：设置 → 个性化 → 开始 → "选择哪些文件夹显示在开始菜单上"，可在边栏添加文档/下载/图片/音乐/视频/网络/个人文件夹

## 2.3 中间应用列表区

- **宽度**：约 260px（固定）
- **背景**：浅色 `#F8F8F8` / 深色 `#1A1A1A`
- **垂直滚动**：超出高度时滚动，滚动条 12px 宽（悬停时显示）
- **内容从上到下**：

### 2.3.1 "最近添加"分组（条件显示）
- **标题**："最近添加"，12px 粗体，距左 16px，距顶 12px
- **项数**：最多 3 项
- **每项高度**：32px
- **每项布局**：图标 24×24px（距左 16px），名称 12px（距图标 10px）
- **"新增"标记**：应用名称右侧显示"新增"标签（蓝色文字 11px）
- **数据来源**：IAppSourceService.GetNewlyInstalledApps()
- **可关闭**：设置中关闭"显示最近添加的应用"

### 2.3.2 "最常用"分组（条件显示）
- **标题**："最常用"，12px 粗体
- **项数**：最多 6 项
- **每项高度**：32px，图标 24px + 名称
- **数据来源**：IRecentItemsService.GetRecentPrograms(6)
- **可关闭**：设置中关闭"显示最常用的应用"

### 2.3.3 所有应用字母索引列表
- **字母头**：A-Z 分组，每组标题 11px，浅色 `#666`，距左 16px，上下 4px
- **应用项**：高度 32px，图标 24×24px（距左 16px），名称 12px
- **字母快速跳转**：点击任意字母头弹出全屏字母表覆盖层（A-Z 方块网格），点击字母滚动到对应位置
- **排序**：按名称字母顺序，中文按拼音排序
- **UWP 应用**：与 Win32 应用混排，图标来自 IAppIconService
- **右键菜单**：
  - 固定到"开始"屏幕（磁贴）
  - 固定到任务栏
  - 更多 → 以管理员身份运行 / 打开文件位置 / 评分和评价 / 共享
  - 卸载
- **悬停**：背景 `#E5E5E5` / `#333`

## 2.4 右侧磁贴区

- **宽度**：窗口宽度 - 48px - 260px - 边框
- **背景**：浅色 `#F2F2F2` / 深色 `#202020`
- **内边距**：左 12px，右 12px，顶 12px
- **内容**：可命名的磁贴分组，垂直排列

### 2.4.1 磁贴分组
- **分组标题**：12px 粗体，距组内第一个磁贴上方 16px，距左 4px
- **标题可编辑**：点击标题进入编辑模式（文字变输入框）
- **默认分组**："生产力"（Productivity）、"播放和浏览"（Play and explore）
- **分组可拖拽**：拖拽分组标题可整体移动
- **分组间距**：组与组之间 24px

### 2.4.2 磁贴网格
- **基本单元**：小磁贴（Small）= 1×1 = 约 48×48px（含 4px 间距）
- **磁贴尺寸**：

| 尺寸 | 单元格 | 像素（含间距） | 内容 |
|------|--------|---------------|------|
| 小 Small | 1×1 | 48×48 | 仅图标（24px居中） |
| 中 Medium | 2×2 | 100×100 | 图标 32px + 名称（底部12px，最多1行） |
| 宽 Wide | 4×2 | 204×100 | 图标 + 名称 + Live Tile 内容 |
| 大 Large | 4×4 | 204×204 | 图标 + 名称 + 大尺寸 Live Tile 内容 |

- **列数**：默认 3 列中等磁贴（每列约 100px），开启"显示更多磁贴"为 4 列
- **磁贴背景色**：每个磁贴有主题色（从应用图标提取或使用系统色），浅色模式下磁贴背景为应用色，文字白色
- **磁贴圆角**：3px
- **磁贴间距**：4px（相邻磁贴之间）
- **图标位置**：中等磁贴图标在中上部（距顶 20px，水平居中），名称在底部（距底 8px）
- **动态磁贴（Live Tile）**：
  - 支持的应用（邮件/天气/日历/新闻）显示实时内容
  - 轮播动画：每 5–15 秒切换内容，从右侧滑入
  - 右键可关闭动态磁贴
  - 实现：UWP 应用通过 Windows.UI.Notifications；Win32 应用不支持（显示静态图标）

### 2.4.3 磁贴交互
| 操作 | 行为 |
|------|------|
| 左键单击 | 启动应用 |
| 右键 | 上下文菜单（从开始屏幕取消固定/调整大小/关闭动态磁贴/固定到任务栏/评分/卸载） |
| 拖拽 | 移动磁贴位置，其他磁贴自动让位（平移动画） |
| 拖拽到分组标题旁 | 创建新分组 |
| 两个磁贴叠放 | （Win10 不支持文件夹，Win11 才支持） |

### 2.4.4 调整大小
- 拖拽右边缘：只改变磁贴区宽度，应用列表宽度不变
- 拖拽上边缘：整体高度变化，应用列表和磁贴区同时增加可见行数
- 磁贴区宽度变化时，磁贴自动重排（响应式网格）

## 2.5 搜索行为

Win10 布局**没有独立搜索框**（与 Win7 不同）：
- 菜单打开后直接键入，顶部展开搜索结果面板
- 搜索结果面板覆盖应用列表和磁贴区
- 顶部显示最佳匹配（大图标+名称），下方分类显示
- 按回车启动最佳匹配
- 按 Esc 清除搜索，返回正常视图

# 三、Windows 11 布局

## 3.1 整体结构

```
┌──────────────────────────────────────────────┐
│                                              │
│  ┌────────────────────────────────────────┐  │
│  │ 🔍 键入以搜索                           │  │
│  └────────────────────────────────────────┘  │
│                                              │
│  已固定                            所有应用 > │
```

- **圆角**：窗口 8px 圆角
- **背景**：Mica 半透明材质（走 IVibrancyService）

## 3.2 搜索框（顶部）

- **位置**：顶部，距顶 36px
- **宽度**：560px（= 640 - 40×2）
- **高度**：40px
- **圆角**：4px（搜索框本身是圆角矩形）
- **背景**：浅色 `#FFFFFF`（不透明，搜索框是实心）/ 深色 `#2D2D2D`
- **边框**：1px `#E5E5E5`，聚焦 `#0078D4`
- **结构**：
  - 左侧：放大镜图标 16×16px，距左 12px，颜色 `#666`
  - 文字区："键入以搜索"提示文字，14px Segoe UI Variable，颜色 `#666`
- **行为**：
  - 点击搜索框 → 打开独立搜索面板（不在菜单内展开结果）
  - 菜单打开后直接键入 → 自动跳转搜索面板并填入字符
  - 搜索面板是独立窗口，不在本文档范围
- **注意**：22H2 后搜索框可能显示搜索亮点（Search Highlights），复刻时不做

## 3.3 固定应用区（Pinned）

### 3.3.1 标题栏
- **位置**：搜索框下方，距搜索框 24px
- **高度**：24px
- **左侧文字**："已固定"（Pinned），14px 粗体 Segoe UI Variable
- **右侧按钮**："所有应用 >"（All apps），12px，颜色 `#0078D4`，点击进入所有应用列表视图
- **布局**：左右两端对齐

### 3.3.2 固定应用网格
- **位置**：标题栏下方，距标题 8px
- **列数**：6 列
- **行数**：默认 3 行（= 18 个图标）；小屏幕 2 行（= 12 个）
- **单元格尺寸**：约 88×88px（图标 48px + 名称 + 间距）
- **图标**：48×48px，水平居中，距单元格顶部 8px
- **名称**：12px，图标下方 4px，水平居中，最多 2 行，超出省略号
- **水平间距**：图标之间约 8px
- **垂直间距**：行间距约 4px
- **悬停背景**：浅色 `#F0F0F0` / 深色 `#333333`，圆角 4px
- **选中背景**：浅色 `#E0E0E0` / 深色 `#444444`

### 3.3.3 分页（22H2+）
- 当固定项超过 18 个时，右下角显示翻页控件
- 翻页控件：左右箭头 + 页码点（如 ●○○）
- 点击箭头切换页面，每页 18 个
- 支持鼠标滚轮翻页

### 3.3.4 图标文件夹（22H2+）
- 拖拽一个图标到另一个图标上，合并为文件夹
- 文件夹显示为：前 2–4 个小图标（24×24）拼成的方块，无名称
- 点击文件夹：展开为弹出面板（约 360×360px），显示文件夹内所有图标
- 文件夹可命名（展开后顶部编辑名称）
- 拖拽出文件夹可取消分组

### 3.3.5 右键菜单
- 从开始菜单取消固定
- 移动到顶部（Move to front）
- 固定到任务栏
- 更多 → 以管理员身份运行 / 打开文件位置 / 卸载
- 调整大小：Win11 固定区图标不可调大小（统一 48px），只有所有应用列表中的磁贴概念已取消

### 3.3.6 布局选项（设置 → 个性化 → 开始）
| 选项 | 固定区行数 | 推荐区行数 |
|------|-----------|-----------|
| 更多固定项 | 4 行（24个） | 1 行 |
| 默认 | 3 行（18个） | 2 行 |
| 更多建议 | 2 行（12个） | 3 行 |

## 3.4 推荐区（Recommended）

### 3.4.1 标题栏
- **位置**：固定区下方，距固定区 24px
- **高度**：24px
- **左侧文字**："推荐"（Recommended），14px 粗体
- **右侧按钮**："更多 >"（More），12px 蓝色，点击打开完整推荐列表
- **可关闭**：设置中关闭"显示最近添加的应用""显示最近打开的项目"后推荐区隐藏

### 3.4.2 推荐项目网格
- **列数**：2 列（默认）
- **行数**：默认 2 行（= 4 项）；"更多建议"时 3 行（= 6 项）
- **卡片尺寸**：约 276×52px
- **卡片布局**：
  - 左侧：应用/文件图标 32×32px，距左 8px，垂直居中
  - 右侧文字区：
    - 第一行：名称，12px，粗体，距图标 10px，距顶 8px
    - 第二行：副文本，11px，颜色 `#666`
      - 新装应用："最近添加的应用"
      - 最近文件：文件路径（如 "Documents\report.docx"）
- **卡片背景**：透明，悬停浅色 `#F0F0F0` / 深色 `#333`，圆角 4px
- **点击**：启动应用或打开文件
- **数据来源**：
  - 最近添加：IAppSourceService.GetNewlyInstalledApps()
  - 最近文件：IRecentItemsService.GetRecentDocuments()
- **右键菜单**：从列表删除 / 打开文件位置 / 固定到快速访问

## 3.5 底部账户栏

- **位置**：菜单最底部，贴底
- **高度**：56px
- **背景**：浅色 `#F8F8F8` / 深色 `#202020`（比内容区略深/略浅以区分）
- **上边框**：1px `#E5E5E5` / `#333`
- **左侧**：用户头像 + 用户名
  - 头像：28×28px 圆形，距左 40px，垂直居中
  - 用户名：12px，距头像 10px，垂直居中
  - 悬停背景：圆角 4px
  - 点击：弹出账户菜单（更改账户设置 / 锁定 / 注销 / 切换用户）
- **右侧**：电源按钮
  - 位置：距右 40px，垂直居中
  - 尺寸：36×36px，图标 16px
  - 悬停背景：`#E5E5E5` / `#333`，圆角 4px
  - 点击：弹出电源菜单（睡眠/关机/重启），向上弹出
  - 数据来源：IPowerManagementService
- **可扩展**：设置中可在电源按钮旁添加文件夹快捷方式（文档/下载/图片等）

## 3.6 所有应用列表视图

点击"所有应用 >"后进入：
- 固定区和推荐区隐藏，显示完整应用列表
- 顶部显示"所有应用"标题 + 返回箭头
- 字母索引列表（A-Z），每项高度 40px，图标 24px + 名称 14px
- 字母头 12px，点击弹出字母表快速跳转
- 搜索框仍在顶部，可直接搜索
- 最近添加的应用旁有"新增"标签
- 右键菜单同 Win10

## 3.7 搜索行为

- 菜单打开后直接键入 → 打开搜索面板（独立窗口）
- 搜索面板不在开始菜单窗口内，由 shell-search 服务驱动
- 按 Esc 从搜索面板返回开始菜单（如果搜索面板覆盖了菜单）

# 四、三种布局对比总结

| 维度 | Win7 | Win10 | Win11 |
|------|------|-------|-------|
| 宽度 | 400px（可调） | 640px（可调） | 640px（固定） |
| 高度 | ~520px（自适应） | 640px（可调） | 720px（固定） |
| 栏数 | 双栏 | 三栏（rail+列表+磁贴） | 单栏垂直堆叠 |
| 程序展示 | 最近使用+所有程序树 | 字母列表+磁贴 | 固定网格+推荐 |
| 搜索框 | 底部内嵌 | 无框（键入即搜） | 顶部内嵌（跳转搜索面板） |
| 电源按钮 | 右栏底部（文字按钮+箭头） | 左侧rail底部（图标） | 底部栏右侧（图标） |
| 用户头像 | 右栏顶部（大头像） | 左侧rail中部（小头像） | 底部栏左侧（小头像） |
| 动态内容 | 无 | Live Tile 磁贴 | 无（推荐区静态列表） |
| 可调整大小 | 是（右边框） | 是（右/上边框） | 否 |
| 磁贴/图标尺寸 | 16px小图标 | 4种磁贴尺寸 | 统一48px图标 |
| 文件夹分组 | 程序树文件夹 | 磁贴分组（命名） | 图标文件夹（22H2） |
| 毛玻璃 | Aero Blur | 无（纯色） | Mica |
| 圆角 | 6px | 0px（直角） | 8px |

# 五、实现优先级建议

| 阶段 | 布局 | 内容 |
|------|------|------|
| P0 | Win7 | 双栏骨架 + 程序列表 + 搜索框 + 关机按钮（最经典，依赖最少） |
| P1 | Win11 | 固定网格 + 推荐区 + 底部栏（结构简单，无磁贴动画） |
| P2 | Win10 | 三栏 + 字母列表 + 磁贴网格 + Live Tile（最复杂，最后做） |

# 六、共享数据接口

三种布局都通过以下服务获取数据（来自 OPEN_SHELL_INTEGRATION_STEPS.md 的服务包）：

| 数据 | 服务接口 |
|------|---------|
| 程序树/所有程序 | IAppSourceService.GetProgramTree() / ScanStartMenu() |
| 最近使用程序 | IRecentItemsService.GetRecentPrograms() |
| 最近文件 | IRecentItemsService.GetRecentDocuments() |
| 新装应用 | IAppSourceService.GetNewlyInstalledApps() |
| 固定项 | IPinningService.GetPinned("startmenu") |
| 搜索 | IStartMenuSearchService.SearchAsync() |
| 电源操作 | IPowerManagementService |
| 运行状态 | IWindowTrackerService.IsRunning() / Activate() |
| 图标 | IAppIconService |
| 启动程序 | IAppSourceService / IWindowTrackerService.Activate |
