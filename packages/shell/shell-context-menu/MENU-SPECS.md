# shell-context-menu · 分场景菜单规格（MENU-SPECS）

> 配套 `shell-context-menu/README.md`（组件设计稿）。本文定义**每一种触发场景**下右键菜单的界面与功能布局：菜单项结构、分组/分隔符、图标、行为、置灰条件、动态项、弹层形态。
> 原则：菜单 = **系统基础项 + 插件贡献项 + Shell 原生项** 三层合成，按统一规范排序分组。

## 0. 菜单项来源与合并规则（所有场景通用）

| 来源层 | 说明 | 排序 |
|--------|------|------|
| ① 系统基础项 | 内核/menu-bar 提供的通用项（打开应用管理中心、Cairo 菜单、设置…） | 顶部或按场景 |
| ② 插件贡献项 | `IContextMenuContributor`（Scope+Priority） | 按 Priority 降序，同优先级按注册序稳定 |
| ③ Shell 原生项 | 文件/文件夹场景的 `IContextMenu` verb（native 或 unified 重绘） | 固定区块 |
| ④ 应用上下文项 | 运行项窗口列表、活动应用操作 | 动态区块 |

**分组规范**：
- 菜单分区块，区块间用分隔符：**常用操作组（第一组）→ 管理组（第二组）→ 系统组（第三组）→ 原生组（文件场景）**。
- 【第一菜单原则（用户拍板 2026-09-02）】高频功能一层直达：**禁用"更多…"子菜单收纳**，超出用菜单内滚动；第三方工具项/自定义项/转换项直接平铺第一层（详见 §8.3 修订）。仅集合语义（新建▶/查看▶/排序▶/发送到▶/窗口▶）与动态列表允许子菜单。
- 置灰规则：不可执行项置灰（如"以管理员运行"无 UAC 权限时、无窗口的"关闭所有窗口"）。
- **隐藏优先原则（文件场景，用户拍板 2026-08-22）**：菜单项声明所需文件能力，能力不满足的项**直接不显示**（而非置灰占位）；仅"可能但受限"的少数项（如只读文件删除）置灰并带说明。

**弹层形态**：
- 普通菜单：默认 `MenuHost` 弹层（WPF 菜单项，支持图标/子菜单/分隔符/禁用）。
- 带面板菜单：需要滑块/开关/预览的项（音量/亮度/网络详情/窗口缩略图）展开为**侧向面板**（复用 MenuHost 的面板能力或独立 Flyout）。

## 8. 文件 / 文件夹（Scope: ShellFile）

触发：资源管理器/桌面文件或文件夹右键。**三档呈现**（见 README §7）：

| 档 | 名称 | 说明 | 适用 |
|----|------|------|------|
| 1 | **native** | 完整调用系统 `IContextMenu`，原样显示（含全部第三方扩展项），本组件只做宿主与消息泵 | 兼容/备用（不美观、无二级菜单能力） |
| 2 | **unified（完整模式，唯一呈现档）** | verb 枚举后**重绘**，第三方工具项**直接平铺**在主菜单 | 功能全覆盖、一次点到 |

- 两档执行均走 `IContextMenu.InvokeCommand`（verb 保真），仅**呈现方式**不同。
- 设置：`shell.integration = native | unified`（默认 `unified`）。
  ~~`shell.displayMode = full | grouped`~~ —— **已于 2026-09-03 按 Win10 方针删除：第三方项一律平铺，不做二级收纳、不设"展开/收起"切换。请勿复活（旧 §8.2 grouped 设计同删）。**

### 8.1 unified 模式主菜单结构

```
┌ 常用操作组（系统 verbs，始终在主菜单）────────────────┐
│ 打开 / 编辑 / 打印          (按文件类型)              │
│ 剪切 / 复制 / 粘贴 / 删除 / 重命名 / 属性             │
│ 固定到 Dock / 发送到 ▶                               │
├ 第三方区 ─────────────────────────────────────────────┤
│ 第三方项直接平铺（按分类排序聚拢：压缩→编辑器→办公…）  │
│ 同类相邻、类间一条分隔线；低频项走 Shift 扩展（§8.3）  │
└────────────────────────────────────────────────────────┘
```
- 例外保留的**集合语义子菜单**（Win10 原生就有，非收纳）：`新建 ▶ / 发送到 ▶ / 查看 ▶ / 排序方式 ▶`。

### 8.2 【已删除】第三方工具二级菜单（grouped 模式）

> **本节内容已于 2026-09-03 删除**（原设计：第三方项收进"第三方工具 ▶"二级菜单并按类别分组、底部常驻"展开完整菜单/收起"切换）。
> 删除依据：用户拍板"**以 Win10 为正、以 Win11 为戒**"——单层完整、第三方平铺、低频项用 Shift 扩展而非二级收纳。
> **勿复活**：相关代码（`UserMenuContributor` 的"快捷工具 ▸ 分类 ▸"）与配置键（`shell.displayMode`）已一并移除；如需历史内容请查 Git 记录，不要重新引入该交互。

（原分类关键词表 `filters.ini` 方案随之废弃——分类仅用于**排序聚拢**，不再生成二级菜单。）

### 8.3 默认值与低频项处置

- 默认 `unified`（**第一菜单原则：第三方工具项第一层平铺，不收纳**）；`native` 仅在 unified 出现兼容问题时一键回退。
- 低频/危险项用 **Shift 扩展**（`MenuItemDef.Extended`，按住 Shift 右键显示；`context-menu.extended.always=true` 可常驻），首批：永久删除、以其他用户身份运行、复制到文件夹…

### 8.4 文件属性精准识别与菜单过滤（隐藏无法操作的项）

> 用户要求：精准识别文件属性，**尽量不显示无法操作该文件的选项**。

**识别层（FileClassifier，shell-context-menu 内部服务）**：
- 主信号：`IShellFolder.GetAttributesOf` 的 **SFGAO 标志**（`SFGAO_FOLDER`/`FILESYSTEM`/`READONLY`/`LINK`/`HIDDEN`/`STREAM`/`BROWSABLE`/`REMOVABLE`…）+ 扩展名 → `FileKind`。
- 辅助：`FileAttributes`（只读/隐藏/系统）、回收站判定（父命名空间为回收站时）、快捷方式目标解析（继承目标能力）。
- 输出：

```csharp
enum FileKind
{
    Folder, Drive, File, Shortcut, Executable, Archive,
    Image, Video, Audio, Document, SourceCode, Config,
    SystemFile, InRecycleBin, Unknown
}

[Flags] enum FileCapabilities
{
    Open, OpenInNewWindow, RunAsAdmin, OpenFileLocation,
    Edit, Print, Preview, Copy, Cut, PasteInto, Delete, Rename,
    Properties, Share, Extract, SetAsWallpaper, OpenWith,
    Restore, Browse, PinToDock
}

record FileIdentity(FileKind Kind, FileCapabilities Caps, bool IsReadOnly, bool IsHidden);
```

**菜单项 ↔ 能力映射（过滤依据）**：

| 菜单项 | 所需能力 | 典型判定 |
|--------|----------|----------|
| 打开 | Open | 几乎全部（Unknown 时降级为"选择默认程序"） |
| 在新窗口打开 | OpenInNewWindow | Folder/Drive |
| 以管理员运行 | RunAsAdmin | Executable，或 Shortcut 且目标为 exe |
| 打开文件位置 | OpenFileLocation | 文件系统文件/Shortcut |
| 编辑 | Edit | 文本类（Document/SourceCode/Config）且有关联编辑器；**图片→"编辑"指默认图片编辑器** |
| 打印 | Print | Document/Image 且有关联 |
| 解压到… | Extract | Archive |
| 设为壁纸 | SetAsWallpaper | Image |
| 剪切/删除/重命名 | Cut/Delete/Rename | 文件系统且非只读/非系统保护（只读→置灰带说明） |
| 粘贴 | PasteInto | Folder/Drive |
| 还原 | Restore | 回收站内 |
| 共享 | Share | 文件系统（网络共享可用时） |
| 打开方式 | OpenWith | 无默认关联的 Unknown 类型 |

**过滤策略**：
- 能力不满足 → **隐藏**（不渲染，保持菜单精简）。
- 例外置灰（`hideDisabled=false` 时可显示）：只读/系统文件的 删除/重命名、无 UAC 权限的 以管理员运行——置灰 + tooltip 原因。
- **多选混合类型**：只显示交集能力项（打开/复制/删除/属性…），单文件专属项（编辑/解压/设壁纸）隐藏。
- **未知扩展名无关联**：只显示 打开(选择默认程序) / 复制 / 属性 / 发送到。

**与 verb 过滤联动**：unified 模式枚举的第三方 verb 同样按能力过滤（如 exe 不出现"编辑"类 verb；Archive 才出现解压 verb）。

## 12. 通用交互与约束

- **键盘导航**：方向键移动、Enter 激活、Esc 关闭、Tab 循环、字母快捷键（下划线）。
- **动态项刷新**：窗口列表/设备列表在菜单打开时异步构建（可取消）；构建超时 500ms 显示"加载中…"。
- **溢出**：~~组内 >6 项 → "更多…"子菜单~~ **已按 Win10 方针删除（2026-09-03）：禁用"更多…"收纳，超出用整菜单滚动**（第一菜单原则 §0/§8.3）。
- **面板型菜单**：音量/亮度/网络详情等用侧向面板（滑块+开关），面板定位对齐触发项，不遮挡触发点。
- **置灰**：不可执行（无权限/无窗口/硬件缺失）置灰并保留位置，避免菜单跳动。

## 13. 与插件的协作

- `shell-dock` / `shell-menu-bar` / `shell-app-center` 一律经 `IMenuService.ShowAsync(MenuRequest(Scope,…))` 弹菜单，不自绘。
- 插件贡献项用 `IContextMenuContributor(Scope, Priority, Build(target))` 注册到对应场景。
- 窗口缩略图（场景 4/5/9）复用 shell-dock 的 `DwmThumbnail`；面板型菜单复用 MenuHost 面板能力。
