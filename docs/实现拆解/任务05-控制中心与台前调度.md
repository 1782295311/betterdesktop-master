# 任务 05：控制中心 + 台前调度 + 温度/通知（P2）

## 目标

功能托盘（类安卓下拉控制中心）+ 台前调度简化版 + CPU/GPU 温度 + 通知降级方案。

## 控制中心（menu-bar 内 `ControlCenterExtension`）

- 自绘下拉面板（毛玻璃，复用 `shell-core.Vibrancy`）。
- 快捷开关：WiFi / 蓝牙 / 音量 / 亮度 / 麦克风 / 静音 / 飞行模式（复用 shell-status monitor 的 Toggle API）。
- 台前调度入口：显示/隐藏窗口总览面板。
- 亮度 / 音量滑块。

## 台前调度（简化版，独立块）

- 窗口枚举：复用 shell-dock `RunningAppDetector`（EnumWindows + 过滤）。
- 缩略图：复用 shell-dock `DwmThumbnail` / `DockThumbWindow`。
- 布局动作：`SetWindowPos` 按网格平铺（2x2/3xN）+ 显示桌面。
- 范围：先做"窗口总览 + 平铺 + 显示桌面"，不做 macOS 台前调度完整分组语义。

## 温度

- 引 `LibreHardwareMonitor`（先验证 net8 兼容）。
- `ITemperatureMonitor`：CPU/GPU 温度传感器。
- 组件：自绘温度值 + 色阶（<60° 绿 / 60-80° 黄 / >80° 红）。

## 通知（降级）

- 不自建通知中心；不读系统通知（UWP 权限成本高）。
- 方案：调起 Windows 原生通知中心（`Win+N` 等效）+ 应用内自维护通知气泡。

## 依赖方向

依赖任务 2（shell-status）+ 任务 3（menu-bar）+ shell-dock（缩略图/窗口枚举复用）。

## 验收

- [ ] 构建 0 警告 0 错误
- [ ] 控制中心可开关 WiFi / 音量 / 亮度
- [ ] 台前调度可平铺窗口、可显示桌面
- [ ] 温度组件显示真实数值

## 注意

- LibreHardwareMonitor 与 net8.0-windows 的兼容性先做小样验证，不兼容则回退 WMI/ACPI 方案。
- 天气组件需和风天气 key，**不列入本任务**，单独确认后再实现。
