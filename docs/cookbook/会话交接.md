# 会话交接 — 新会话接手标准流程

> 适用：任何对本仓库无记忆的新 AI 会话或新成员。目标是「不靠记忆、只靠仓库」完成冷启动。

## 第一步：读状态与宪法（5 分钟）

按序读：`docs/architecture/STATUS.md`（当前阶段/下一步）→ `AGENTS.md`（全仓规范）→ 最新 ADR（`docs/architecture/ADR-*.md` 中编号最大者）→ `docs/MECHANISMS.md`（机制注册表）→ `docs/coding-standards.md`（代码规则）。

## 第二步：确认基线（2 分钟）

1. `pwsh -v` 确认是 PowerShell 7（**5.1 会把仓库内 UTF-8 脚本读成乱码，禁止使用**）。
2. 跑 `pwsh -NoProfile -ExecutionPolicy Bypass scripts/run-gates.ps1`，必须全绿。
3. 红了 = 要么仓库被破坏（先修复并留记录），要么你的环境有问题（对照 `docs/architecture/环境陷阱.md`，该文件 P1 前落地）。

## 第三步：查历史决策（5 分钟）

浏览 `.agents/notes/implemented/` 按日期倒序读最近 3~5 篇，知道「哪些路已经走过、为什么」。

## 第四步：动手前的四问

1. 我的任务会新增/替换机制吗？→ 先登记 `MECHANISMS.md`，替换需开 ADR。
2. 我的任务会改冻结项（TFM/分层/命名/资产边界）吗？→ 必须新开 ADR。
3. 我的决策算非平凡吗？→ 落决策记录，否则变更可能被打回。
4. 我的任务要**真机验证**吗？→ 验证前必须 `cargo build --release` 并**核对部署副本的时间戳**：
   `cargo test --release` **不刷新** `target/release/*.exe`，跳过这一步会得到「用旧二进制验证新代码」的
   假结论（本仓库实测踩到过）。细则见 [`docs/engineering-conventions.md`](../engineering-conventions.md) 第 11 条。

## 第五步：收工（见 STATUS.md 收工清单）

门禁全绿 + 决策记录/物证齐 + 更新 STATUS.md + 中文范围前缀提交。
