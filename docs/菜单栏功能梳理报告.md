# better-desktop-cordis · 菜单栏（shell-menu-bar）功能梳理报告

> 基于对 `packages/shell/shell-menu-bar` 全量源码的通读整理（2026-08-31）。
> 定位：Windows 桌面外壳顶部全宽菜单栏，Cordis 风格插件内核（C#）下的一个 UI 插件包。

---

## 1. 包定位与外部依赖

**包名**：`BetterDesktop.Shell.MenuBar`（插件 ID `shell.menu-bar`），`net8.0-windows10.0.19041.0`，`TreatWarningsAsErrors=true`。

**依赖工程**（csproj）：
| 依赖 | 用途 |
|------|------|
| `BetterDesktop.Kernel` | `IPlugin` 插件契约、`IContext` 注入 |
| `shell-core` | `ShellWindow` 窗口基类、`IVibrancyService`、`IAppearanceService` |
| `shell-status` | 采集服务契约（`I*Monitor`）+ 原生层（`AudioCoreNative`/`NetworkCoreNative`/`KeyboardLayoutInterop`/`MediaPlayerCore` 等） |
| `shell-settings` | `ISettingsService`、`ISettingsSectionRegistry` 设置分区 |
| `shell-start-menu` | 左区「程序菜单」复用的 `IStartMenuService`（已确认无环） |

**第三方 NuGet**：`LibreHardwareMonitorLib`（CPU 温度）、`ManagedShell`（系统托盘接管）、`System.Drawing.Common`。

**核心原则（贯穿全包）**：
- **界面与数据分离**：菜单栏只负责画，所有数据来自 `shell-status` 注入的监控服务（`I*Monitor`），零硬编码假数据。
- **M10 降级**：监控服务 `context.Get<T>()` 可能为 `null`，对应图标降级为占位，绝不崩溃、绝不放"点了没反应"的假按钮。
- **逻辑单位纪律**：窗口定位/弹窗锚点一律用 WPF 逻辑单位（DIP），物理像素→逻辑单位换算收敛在 `MenuBarScreen`。

## 2. 总体架构（3 层）

```
shell-menu-bar（UI 插件）
├── 入口   MenuBarPlugin（IPlugin）：装配左区 + 右区，主题接线，注册设置分区
├── 主窗口 MenuBarWindow : ShellWindow：全宽置顶毛玻璃，16px 高
│    ├── 左区 MenuBarLeftZone：程序菜单入口 + 位置/下载/文档
│    └── 右区 _rightHost(StackPanel)：横向排布 IMenuBarExtension
│         └── StatusBarMenuBarExtension（唯一扩展点，内部是 MenuBarStatusStrip）
├── 契约层 Contracts/：IMenuBarExtension、MenuBarTheme、MenuBarScreen、PopupAnchor、MenuBarMetrics、ExtensionCatalog、三个 Glyph
├── 状态条 Status/MenuBarStatusStrip：16 个自绘按钮 + 各图标控件
├── 弹窗 Windows/*：13+ 个独立 ShellWindow 面板（MenuBarPopupWindow 基类）
└── 服务 Services/*：数据采集枚举（WiFi/蓝牙/电源/IME）+ 控制中心功能目录 + SMTC 媒体壳
```

**加载流程**（`MenuBarPlugin.LoadAsync`）：
1. `context.Get<T>()` 批量取监控服务（全部可 null）。
2. 主题接线：`MenuBarTheme.SyncFrom(appearance)` + 订阅 `Changed`（图标随主题换色）。
3. 构造 `StatusBarMenuBarExtension`（右区唯一扩展），放进 `extensions` 列表。
4. 构造 `MenuBarWindow(extensions, ...)` 并 `Show()`。
5. 注册设置分区 `MenuBarSection`（系统功能显隐由「设置 → 菜单栏」管理）。

## 3. 左区功能（`MenuBarLeftZone`）

导航入口，与右区"状态展示"职责正交：

| 入口 | 行为 | 说明 |
|------|------|------|
| **程序菜单**（◈） | `startMenu.Toggle()` | 复用 `IStartMenuService`（shell-start-menu）；服务未注入时整个入口**不呈现**（M10 降级） |
| **位置** | 打开 `shell:MyComputerFolder` | 交 explorer 打开 |
| **下载** | 打开 `shell:Downloads` | 用 shell: 协议规避中文 Windows 本地化问题（无 `SpecialFolder.Downloads`） |
| **文档** | 打开用户文档目录 | `SafeGetFolderPath(Personal)`，解析失败不添加入口 |

外观：按钮高 14px（与右区一致），字体 9px 压缩内边距，悬停反馈走 `MenuBarTheme.AttachHoverFeedback`。

> ⚠️ 设计稿 README 里列出的 CairoMenu（20 项系统命令）、分组 Tab + 拖放添加程序、Win 键打开等**尚未实现**，当前左区仅导航入口。

## 4. 右区功能（`MenuBarStatusStrip`）— 16 个自绘按钮

每个按钮 = `Border`（宽 14px 高）+ 图标控件，注册进 `_buttons` 字典供运行时显隐。顺序从左到右：

| # | 按钮 | 图标控件 | 数据/行为 | 左键 | 右键 |
|---|------|---------|-----------|------|------|
| 1 | 系统托盘 | `SystemTrayIcon` | ManagedShell 接管托盘；`HideSystemIcons` 按 Win11 GUID/Win10 dll 双路去重音量/网络/电源/操作中心；图标数动态调宽；可折叠 | 原生托盘交互 | 原生托盘交互 |
| 2 | 帧率 | `FpsIcon` | `CompositionTarget.Rendering` 计帧 + 1s 刷新 | — | — |
| 3 | CPU | `CpuIcon` | `ICpuMonitor`，色阶（`StatusColor.ForSeverity`） | 打开 CPU 面板 | 同左 |
| 4 | 内存 | `MemoryIcon` | `IMemoryMonitor`，色阶 | 打开内存面板 | 同左 |
| 5 | WiFi | `WifiSignalIcon` | `INetworkMonitor` + `WifiGlyph`（0~3 级真实强度/有线水晶头）；5s 独立采样 `wlanapi` 信号 | 打开 WiFi 面板 | 同左 |
| 6 | 网络流量 | `NetworkTrafficIcon` | `NetworkCoreNative.ReadPrimary()` 差分算上下行速率（1s） | 打开网络详情 | 同左 |
| 7 | 亮度 | `BrightnessIcon` | `IBrightnessMonitor`，8 条光线按级点亮 | 打开主题/亮度面板 | 同左 |
| 8 | 输入法 | `ImeIcon` | `IImeMonitor` + `KeyboardLayoutInterop` 取真实图标；TSF 显示图标，纯键盘显示"ENG" | **切换下一个输入法**（`ImeLayoutEnumerator.CycleOnce`） | 打开 IME 面板 |
| 9 | 蓝牙 | `BluetoothIcon` | 自绘 | 打开蓝牙面板 | 同左 |
| 10 | 音量 | `VolumeIcon` | `IVolumeMonitor`，波形按级点亮 | 打开声音面板 | 同左 |
| 11 | 麦克风 | `MicIcon` | `IMicrophoneMonitor`，静音划线 | 打开麦克风面板 | 同左 |
| 12 | 电池 | `BatteryIcon` | `IBatteryMonitor`，充电闪电/低电量红色 | 打开电源面板 | 同左 |
| 13 | 通知中心 | `NotificationToggle` | CapsuleSwitch 视觉（本地开关，未接系统通知中心） | Toggle 视觉 | 打开控制中心 |
| 14 | 扩展中心（+） | TextBlock "+" | 打开扩展管理面板 | 打开扩展中心 | 同左 |
| 15 | 日期时间 | TextBlock | 对齐到分钟边界重排的 DispatcherTimer（分钟切换零延迟、比 1s 轮询省 60 倍） | 打开日历 | 同左 |
| 16 | 桌面覆盖 | 自绘图标 | `ShellExecute` 桌面协议 / 兜底 Win+D 键 | 显示桌面 | 同左 |

**交互统一**：悬停变亮/点击变深走 `MenuBarTheme` 共享冻结画刷（不每次 new）；点击回调 `ButtonClicked` 事件，由 `StatusBarMenuBarExtension.OnButtonClicked` 分发到各面板。

## 5. 弹窗面板（`Windows/*`，均继承 `MenuBarPopupWindow`）

`MenuBarPopupWindow : ShellWindow` 提供统一能力：无边框透明置顶、不透皮肤图（透 DWM 毛玻璃）、**失焦自动收起**（`Deactivated` + 全局低级鼠标钩子点击窗口外收起）、`ShowActivated=false`（不抢输入法焦点）、主题令牌外观（背景/描边/圆角/前景）。

`StatusBarMenuBarExtension` 维护 13 个面板单例 + **弹窗互斥**（仿 macOS 同时只开一个，`CloseAllExcept`）。

| 面板 | 尺寸 | 功能要点 |
|------|------|---------|
| IME 输入法 | 290×320 | 切换按钮 + 真实布局列表（图标/方块字/勾选）+ Shift 秒切中英 + 三条微软 IME 注册表设置 + **输入法管理子视图**（上移/下移/设默认/删除/添加） |
| 电源/电池 | 290×420 | 电池状态 + 性能模式图标（`PowerGlyph` 自绘节能/平衡/高性能/卓越）+ 偏好链接 |

| CPU | 340×300 | 真实 CPU 占用柱状图 |
| 麦克风 | 320×360 | 输入音量整数滑块 + 输入设备枚举 |
| 声音 | 320×420 | 输出音量 + 真实音频会话 + SMTC 播放控制 |
| WiFi | 320×520 | 当前连接（`WifiEnumerator`）+ 附近网络扫描（8s 超时）+ 连接/断开/密码连接（`WlanInterop`） |

## 6. 控制中心（功能托盘）— `ControlCenterWindow`

macOS 风格面板，两个入口（通知图标 + 扩展中心+）：

**顶部连接区（6 行纵向条目）**：
| 项 | 左键 | 右键 | 数据源 |
|----|------|------|--------|
| Wi-Fi | 切换无线电（`RadioInterop` WinRT） | 打开 WiFi 面板 | `WifiEnumerator` |
| 蓝牙 | 切换无线电 | 打开蓝牙面板 | `BluetoothEnumerator` |
| 热点 | 打开 ms-settings:network-mobilehotspot | 同左 | 空壳 |
| 专注助手 | ms-settings:quietmoments | 同左 | 空壳 |
| 台前调度 | ms-settings:multitasking | 同左 | 空壳 |
| 投影 | ms-settings:project | 同左 | 空壳 |

**三张模块卡片**（统一 BuildModuleCard「标题左/数值右」）：
- **显示器**：亮度滑块（实时）
- **声音**：音量滑块（流畅滑杆，拖动只更 UI、松手才调 API）+ **麦克风静音按钮**（`AudioCoreNative.SetCaptureVolume`，橙底=静音）
- **正在播放**：SMTC 媒体（`MediaSessionController` 2s 轮询 + 命令即时回读），上一首/播放暂停/下一首真实媒体命令

**功能目录**：`ControlCenterFeatureCatalog.Build` 每项 = `(Title, Summary, OnActivate, ToggleAsync?)`，`ControlCenterWindow` 只承载简略视图，点击唤起各功能**自己的独立完整面板**。

**图标**：全部用 `ControlCenterGlyph`（24×24 纯自绘，11 图标 + 4 媒体几何），Wi-Fi 复用 `WifiGlyph`，杜绝 Segoe MDL2 码位字形错乱。

## 7. 设置集成（`Sections/MenuBarSection`）

「设置 → 菜单栏」分区，两栏网格 15 项系统功能 + 托盘去重开关：
- 每项开关写 `extensions.<id>.enabled`（`ISettingsService`），切换即时调 `StatusBarMenuBarExtension.SetComponentVisible` 显隐（先落盘再应用）。
- **职责边界**：系统功能归设置管；「+」扩展中心只管**外部扩展插件**。
- 托盘隐藏重复系统图标开关持久化 `menubar.tray.hideSystemIcons`（默认 true）。

## 9. 数据源与技术选型汇总

| 能力 | 实现方式 | 关键点 |
|------|---------|--------|
| 系统托盘 | `ManagedShell` 接管 `Shell_TrayWnd` | `PinnedNotifyIcons` 必须显式赋值否则 NRE 吞掉托盘为空；Reset 事件整表重建；双击阈值取系统 `GetDoubleClickTime` |
| WiFi | `wlanapi.dll` P/Invoke + `WlanCore.dll` 原生层双路 | SSID 按 UTF-8 严格解码否则 Latin-1；密码连接写 WPA2PSK profile XML |
| 蓝牙 | `bthprops.cpl`（`BluetoothFind*`） | SYSTEMTIME 结构 16 字节不能拿 long 顶替；CoD 分类设备图标 |
| 无线电开关 | WinRT `Windows.Devices.Radios.Radio` | 免管理员；2s 缓存 |
| 音量/麦克风 | `AudioCoreNative`（Core Audio） | `AudioFlow.Render/Capture` 分离 |
| 亮度 | `IBrightnessMonitor`（DDC/WMI） | 滑杆 `CreateCircleThumbSliderStyle` |
| IME | `KeyboardLayoutInterop`（imm32 + 注册表） | TSF 走 `ActivateProfile`，IMM 走窗口消息；枚举 HKLM Keyboard Layouts + HKCU Preload |
| CPU | `LibreHardwareMonitorLib` | 独立采集 |
| 媒体 | `MediaPlayerCore`（SMTC）→ `MediaSessionController` 薄壳 | 2s 轮询，命令后即时回读 |
| 显示桌面 | `ShellExecute` 桌面协议 / 兜底 Win+D | |

## 10. 关键设计约定 / 质量观察（代码审查视角）

**优点（强约束贯彻到位）**：
1. **零硬编码数据**：所有图标/数值/列表来自系统真值；假数据只出现在"占位/空壳"且语义明确。
2. **降级成文化（M10）**：服务 null、P/Invoke 失败、扫描超时均静默降级，绝不崩溃，图标可读性优先（如断网空扇形避免误导）。
3. **单位纪律**：`MenuBarScreen`/`PopupAnchor` 统一逻辑单位，DPI 换算与"取锚点所在显示器"集中收口，杜绝历史偏移 bug。
4. **主题单一真相源**：`MenuBarTheme` 共享未冻结画刷，"改一次=全菜单栏换色"，等效 DynamicResource 且零结构改动；弹窗用 `ApplyContent` + 递归 `BindThemeForeground`。
5. **性能细节**：时钟对齐分钟边界（省 60 倍唤醒）；Wifi 信号 5s 采样；托盘图标动态调宽；网络速率 1s 差分；共享冻结画刷降 GC。
6. **防错注释**：每处"踩坑"（`PinnedNotifyIcons` NRE、SYSTEMTIME 结构、`MediaPlaybackState` 命名空间坑、`Reset` 整表重建）都有根因注释。

**可留意的点（非缺陷，供参考）**：
- `MenuBarStatusStrip`/`MenuBarStatusButtonId` 位于 `Status/` 文件夹，命名空间写 `Status`（`BetterDesktop.Shell.MenuBar.Status`）。
- `MenuBarExtensions.cs` 里有 3 个 IMenuBarExtension 实现（Ime/Cpu/Calendar/ControlCenter），但 `MenuBarPlugin` 实际只装配了 `StatusBarMenuBarExtension` 一个 —— 存在**两套扩展体系**（老的 `MenuBarExtensions` 类 vs 新的 `StatusBarMenuBarExtension`），部分为 Playground/历史迁移遗留，`MenuBarExtensions` 中的 Ime/Cpu 扩展可能与状态条里的 ImeIcon/CpuIcon 功能重叠。
- `README` 开放问题仍挂账：功能托盘具体清单部分为空壳（热点/专注/台前调度/投影仅跳系统设置）、CairoMenu 20 项命令未实现、每显示器一个菜单栏未实现、通知按钮未接系统通知中心。
- `MenuBarSection` 网格每项 `ToggleRow` 两列布局，行定义只在第一列新增，实现正确但可读性一般。
- `MenuBarPopupWindow` 的菜单栏条带判定 `MenuBarStripHeight=20` 与 `MenuBarMetrics.MenuBarHeight=16` 不同源，存在轻微漂移风险（条带识别区域略大于实际窗口）。
- 右区按钮宽度多为手写常量（如 54/56/80），若新增按钮需留意总宽与多屏适配。
