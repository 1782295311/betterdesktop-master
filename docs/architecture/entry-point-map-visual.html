关键要点

要点 说明
三种"启动世界" ① 双击启动器（全套拉齐）② 开机自启（由 Run 值决定）③ 单独双击某个 exe（只起来那一个+兄弟）
谁不被守护 Tray / Capture / Index.Engine — 有意设计，后者按需自退，守护会与退场打架
Host 现在也拉起别人 桌面服务（尊重留痕）、Agent（尊重留痕）、Tray（不留痕，无抑制）— 2026-09-18 新增
开关 ≠ 拉起进程 开关只改"下次要不要"或让正在跑的进程自己动，不直接拉进程
