# 环境陷阱.md — 本机环境与工具链陷阱登记

> 地位：所有「在本机踩过、换环境会再踩」的坑集中于此（cookbook 引用本文件）。**每踩一个新坑，必须在此登记**。
> 抽象为通用规则的部分见 [`../lessons.md`](../lessons.md)。

## 已踩实坑（均有对应处置）

| # | 陷阱 | 症状 | 处置 |
|---|---|---|---|
| 1 | Windows PowerShell 5.1 读 UTF-8 无 BOM 脚本 | 中文注释乱码 → 解析错误 → 门禁假红 | 唯一合法解释器 PowerShell 7（AGENTS.md 已冻结） |
| 2 | git 不跟踪空目录 | 类别目录在新鲜克隆中消失 → 门禁红 | 空目录放 `.gitkeep`（已补） |
| 3 | 变红取证误用 `git add -A` | 未提交改动被打包进注入提交、随 revert 全部被撤 | 门禁契约第 8 条：注入提交只准精确暂存 |
| 4 | PowerShell 脚本块作用域陷阱 | 脚本块内 `+=` 只改局部副本，父作用域集合永远为空 → 门禁永不红 | 跨作用域累加用 `$script:` 前缀（md-wrap 已修） |
| 5 | CRLF/LF 混用 | diff 全行判异（老仓 MenuBar 对比曾因此误判「整文件重写」） | 仓库统一 LF；对比用 `--strip-trailing-cr` |
| 6 | `git show <rev>:<path>` 路径写错（多点一个点） | 物证里引用不到注入内容 | 取证脚本先验证路径再记录 |

## P1 起预告的坑（提前登记，落地时补实）

- ALC 卸载：静态字段 / 事件订阅 / 未释放句柄会阻止 AssemblyLoadContext 回收——内核代码零静态引用（coding-standards 已冻结）。
- WPF STA：内核状态机在线程池，UI 操作必须经 Dispatcher 服务封送（ADR-001 已冻结）。
- .NET SDK 版本漂移：`global.json` 落地前，不同 SDK 构建行为可能不一致（build-release.md 已冻结）。
