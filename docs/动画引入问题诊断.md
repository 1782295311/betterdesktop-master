## 〇、关键认知修正（最重要）

**沙箱诊断测试的致命盲区**：第一版 `WindowCreationReproTests` 用 `FakeVibrancy` / `FakeDockApps` / `FakeIcon` 把所有真实依赖替换成空实现，且**没有跑 `Bootstrap.Build()` 真实启动链路**。它测的只是"窗口类能不能实例化"，完全跳过了真机崩在的真实服务初始化路径：

- 真实 `DockAppsService` 构造（依赖 `IAppSourceService`）
- `AppSourceService.ScanStartMenu()` 扫描**真实** StartMenu 目录
- `VibrancyService.Apply` 调**真实 DWM**（`DwmExtendFrameIntoClientArea` / `SetWindowCompositionAttribute`）
- `RunningAppDetector.GetRunningWindows()` 枚举**真实**桌面窗口

**重写后的诊断测试**改为直接调用 `Bootstrap.Build()`（引用 host 工程，STA 线程里 `new Application()` + Build + DispatcherFrame 跑 Loaded）——但**沙箱 headless 环境下 DWM/桌面合成路径"侥幸"不抛，仍全绿**。真机崩溃依赖真实桌面合成/DWM 行为，**沙箱不可复现**。

> 结论：诊断 WPF/Win32 桌面程序的"窗口创建崩溃"必须用**真实依赖 + 真实 Bootstrap 启动链路**；headless 沙箱对 DWM/桌面合成相关崩溃天然不可复现，最终要靠真机异常落盘。

## 一、已做的确定性修复（即便不是真凶，也无副作用）

### 1. AppGrabberWindow XAML 初始化期事件陷阱（已修）
- `AppGrabberWindow.xaml` 第 47 行 `FilterAll` 的 `IsChecked="True"` + `Checked="OnFilterChanged"`，会在 `InitializeComponent` 期间同步触发 `DisplayCurrent()` 访问尚未初始化的 `ContentPanel` → NRE。
- 修复：去 `IsChecked="True"`；改到 `OnLoadedCore`（ContentPanel 就绪后）设默认筛选；`DisplayCurrent` 加 null 防御。
- **说明**：这确实是真 bug（沙箱可复现），但用户真机"全崩"表明它不是唯一/主因。

### 2. DockWindow 窗口级 RenderTransform 滑动动画冲突（已按授权移除）
- 分层透明窗口 + Window 级 RenderTransform 位移动画会累积偏移、与 Top/Left 定位冲突。
- 按"冲突就不要动画"授权，改为 Opacity 淡入淡出；保留项级图标悬停/点击动画。

### 3. 全局异常落盘补丁（关键根因抓取手段，新增）
- `host/App.xaml.cs` 挂 `DispatcherUnhandledException` + `AppDomain.UnhandledException`：
  - 任何窗口 `Loaded` / 交互中未捕获的异步异常**不再直接终止进程**；
  - 把异常类型/消息/堆栈（含 InnerException）**落盘到桌面 `BetterDesktop_crash.log`**；
  - `Bootstrap.Build()` 同步异常也 catch 落盘 + 弹窗提示。
- 这是目前**唯一能在真机拿到真实崩溃堆栈**的手段。

## 二、已审查并排除的真实路径（均有 try/catch 或无崩点）

| 路径 | 结论 |
|---|---|
| `Win32ShellIconService.GetIconAsync` / `ExtractIconAsync` | 全程 try/catch，提取失败返回 null，不崩 |
| `ShellLinkResolver.Resolve*` | 全程 try/catch，解析失败回退文件名，不崩 |
| `RunningAppDetector.GetRunningWindows` | EnumWindows 回调内 try/catch，单窗口异常不影响枚举 |
| `DwmHelper.EnableAcrylic/BlurBehind/Disable` | P/Invoke 返回 int 未查 HRESULT，失败静默，不抛托管异常 |
| `AppSourceService.ScanStartMenu` / `ScanDirectory` | `EnumerateFiles` 外层 try/catch，目录访问失败不阻断 |
| `VibrancyService.Apply` | 仅转发 DwmHelper，不抛 |
| `AdvancedVibrancyService` | **死代码**（未被任何地方注册/实例化），非真凶 |
