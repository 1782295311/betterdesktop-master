# product-quality.md — 产品质量规则（性能 / 可访问性 / 本地化 / 数据 / 隐私）

> 地位：用户直接感知的质量底线（MECHANISMS.md M13）。外壳产品的质量就是这些细节的乘积。

## 一、性能预算

1. 冷启动到可用 ≤ 目标值（P2 实测定基线后棘轮锁定）；常驻内存 ≤ 目标值。
2. UI 交互处理预算：单次操作主线程阻塞 ≤ 16ms（一帧）；长任务一律移出 UI 线程。
3. 回归超 10% 即红（testing.md 已冻结基准机制）。

## 二、可访问性

1. 全部功能键盘可达；焦点管理有明确规则。
2. 高对比由主题令牌支持（ui-foundation 令牌体系），不得另行硬编码。
3. 控件提供屏幕阅读器可读名称；DPI 声明 PerMonitorV2（已冻结）。

## 三、本地化

1. UI 文案一律资源化（资源字典/资源文件），**禁止硬编码可见字符串**。
2. 语言包独立于代码包（P2 结构冻结）；日期/货币走系统文化设置。

## 四、设置与数据

1. 设置持久化单一来源（对应老仓 M12 教训：禁止第二份设置文件 / 静态访问点）。
2. 设置与数据 schema 必须版本化并带迁移器；破坏性迁移 = 新开 ADR。
3. 用户数据目录规范统一（P2 冻结路径布局），禁止各包自创散落目录。

## 五、隐私

1. 遥测默认关闭或 opt-in；数据本地优先。
2. 收集任何数据必须在隐私说明中明示（P2 落地）。

## 机检状态（诚实标注）
