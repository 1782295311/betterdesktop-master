## 背景（为什么必须跨语言）

- **UE5 桌宠舞台**（`PetStage/`，工作区根）：VRM→ChaosCloth/Groom 深度物理→烘焙 `.cairocompanion`——3D 物理保真只有 UE5/C++ 能做，C# 无法替代。
- **FFmpeg 视频**（动态壁纸/高速缩略图）、**Everything 式索引搜索**、**DSP 引擎**：原生性能/生态锁死。
- 原则：C# 插件体系保持干净；性能敏感块 = **独立原生进程 + IPC**，崩溃隔离白赚。

## 关键决策（已定）

- 统一走**独立进程**（第三档），不采用进程内脚本引擎（Jint/Python.NET）——隔离与崩溃安全优先。
- 协议基线 **JSON-RPC 2.0 风格**，通道 stdio（Phase 1）→ 命名管道（可选）→ 共享内存（大块数据）。
- `cordis.yml` 扩展 `type: external` + command/args/env/workdir + protocol 版本。
- 宿主侧唯一入口：`ExternalPluginAdapter : IPlugin`（内核侧代理，其余内核代码零改动）。
