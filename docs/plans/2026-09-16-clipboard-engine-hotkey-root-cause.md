# 剪贴板「引擎未连接 / 热键失效」根因与修复计划（2026-09-16）

> 状态：**根因已定位，待实施修复**（用户在 2026-09-16 追问"怎么到现在还没修好"）。
> 本文只讲证据与修复设计，不含已落地的改动。

## 1. 两个症状的现场证据

| 症状 | 证据 | 判定 |
|---|---|---|
| "引擎未连接" | `panel.log`：`2026-09-16 10:37:44 分页加载失败 offset=0: engine disconnected`、`20:45:26 同上`；同日 `11:08:04 已拉起 BetterDesktop.Clipboard.Engine.exe` | **引擎被拉起过，但"断开→自动重连"没有闭环**：面板遇到 disconnected 只报错，不主动拉起 + 重试 |
| 热键无法使用 | `settings.json` 只剩 `{"hotkeys-panel.x":"1691","hotkeys-panel.y":"71"}`（**其余键全没了**）；`panel.log` 里 09-13 有 `用户热键已注册：Ctrl+Shift+J`，**09-16 一条都没有** | 用户配置被**清空**，热键键值丢失 → 无热键可注册（不是注册失败，是配置没了） |

## 2. 根因（settings.json 被清空）

**多个进程对同一个 `settings.json` 做"读-改-写"，且没有任何协调**：

| 写者 | 位置 | 写法 |
|---|---|---|
| 宿主设置服务 | `shell-settings/Services/SettingsService.cs` | 内存字典 + debounce 落盘 |
| 系统右键"桌面控制 ▸" | `host/ToggleKeyCommand.cs:89` | **读出整个 JSON → 改一个键 → `File.WriteAllText` 整文件覆盖** |
| 系统右键"切换桌面" | `host/DesktopToggleCommand.cs:77` | 同上 |

后两者是**一次性短命进程**：它读到的文件可能是"另一个写者刚写到一半/刚被清空"的状态，随后**把读到的那份原样写回** —— 只要有一次读到的是不完整内容，其余键就**永久丢失**。文件里只剩 `hotkeys-panel.*` 说明最后一个写者手里只有这两个键。

**旁证**：本会话多次观察到**同时存在 2 个 `BetterDesktop.Host` 进程**（单实例互斥没有兜住），双宿主会让"内存字典"各持一份，落盘互相覆盖。

## 3. 修复设计（按风险从低到高）

1. **原子写 + 滚动备份**（所有写者统一走一个 helper，禁止裸 `File.WriteAllText`）：
   - 先写 `settings.json.tmp` → `File.Replace` 覆盖主文件（同卷原子）；
   - 覆盖前把旧文件复制为 `settings.json.bak`（保留一份上一版）。
2. **防清空守卫（fail-closed）**：写入前比较"新字典键数 vs 现有文件键数"——若非显式重置（无 `--reset` 标记）且新键数明显少于旧文件（例如旧 ≥5 且新 < 旧的一半），**拒绝写入**并记 Warn，同时保留 `.bak`。宁可这一条设置没生效，也不能把用户配置清空。
3. **自动恢复**：启动时若主文件缺失/解析失败/键数为 0~1 而 `.bak` 存在 → 从 `.bak` 恢复并记 Warn（用户无感）。
4. **单实例加固**：宿主与两个 toggle 命令约定"只有宿主是权威写者"；toggle 命令改为**经 `MenuCmd` 管道请求宿主改键**（复用既有通道，M17），不再自己写文件。这样从结构上消灭"第二个写者"。
5. **引擎断开自愈**（剪贴板面板）：捕获 `engine disconnected` → 调 `ClipboardEngineLauncher` 拉起引擎 → 退避重试（1s/2s/4s，上限 3 次）→ 仍失败才在状态槽显示"引擎未连接，点此重试"（可点动作，而不是只报错）。

## 4. DoD

- **D1** 手工把 `settings.json` 清空为 `{}` → 启动宿主：自动从 `.bak` 恢复，日志有 Warn，用户设置与热键回来。
- **D2** 在两个 toggle 命令与宿主之间**同时**改不同键：不发生丢键（键数单调不减）。
- **D3** 杀掉引擎进程 → 面板在 4 s 内自动拉起并恢复列表（不必用户手动重开）。
- **D4** 机检：`SettingsService` 原子写/守卫/恢复三条单测；`verify-dotnet-format` 等门禁 PASS。

## 5. 遗留待确认
