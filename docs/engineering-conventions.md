# engineering-conventions.md — 通用工程铁律

> 地位：跨域通用的工程约定——「必须怎么约定」，与 [`docs/coding-standards.md`](coding-standards.md) 第三节「禁止清单」（「不能做什么」）互补。
> 来源：`参考/deepseek-harness-master` 根 `AGENTS.md` Conventions，已从 TS/Node 适配到 C#/.NET 桌面外壳。
> 每条铁律按诚实标注原则标注机检状态：有门禁标名称，无门禁标「靠评审」。

## 铁律清单

1. **注册即 effect**：`Provide` / `Plugin` / 事件订阅 / 扩展点注册一律返回释放句柄（`IDisposable`），调用方必须持有并在卸载时确定性释放；注册即副作用，不释放即泄漏。（机检：P2 架构测试）
2. **失败大声报错**：配置错误、缺失引用、非法状态必须在能以自包含方式判定的最早点（通常是加载期）显式抛错，绝不静默跳过缺失引用或降级成假成功。（对应 M10 fail-closed；机检：`verify-host-log-sink` + 启动冒烟，其余靠评审）
3. **跨边界 ID 强类型**：跨进程、跨持久化、跨线上的标识一律用专用类型（`readonly record struct` 或强类型包装），禁止用裸 `string`/`Guid` 表示语义不同的 ID。（机检：靠评审）
4. **UI 呈现即日志**：任何进入用户界面或日志的状态都必须能从事件流/会话记录重建（事件驱动可回放），可呈现与已记录等价。（机检：靠评审）
5. **空 catch 必须命名吞什么**：`catch {}` 必须写明吞掉的异常类型与原因、以及为何此处不可能有别的东西；`try` 体保持单语句。（机检：靠评审）
6. **对称性**：并行/成对的值与逻辑保持对称，无法解释的不对称通常意味着漏了一次抽取。（机检：靠评审）
7. **不硬编码可调参数**：部署可变的行为一律走经校验的 `Config` 字段（可从 cordis.yml 改），禁止用 `DEFAULT_*` 常量或测试钩子冒充可配置性；协议常量、外部规范、安全不变量保持固定。（机检：靠评审）
8. **显式 > 隐式（包边界处）**：边界处的默认值必须由拥有方显式 `Resolve(请求): 规格` 得出，禁止隐藏在 `Run()` 内部的 `?? 默认值` 兜底。（机检：靠评审）
9. **测试描述行为而非正确性**：测试断言可观察行为，改实现/改名不应导致仅因措辞而失败的测试；变更行为就改它的测试并说明原因。（机检：`test-coverage` 棘轮）
10. **信任同进程类型边界**：同进程内有编译器类型保证处不加运行时校验、不加兜底、不加恶意输入测试；只在解析器/配置、排队/模型/工具 JSON、持久化/文件、worker/进程、线上边界处校验。（机检：靠评审）
11. **真机验证前先确认二进制是刚构建的**：`cargo test --release` 不刷新 `target/release/*.exe`，必须先 `cargo build --release` 并核对部署副本时间戳。（机检：靠评审）
12. **独占管道名必须显式确权**：`FILE_FLAG_FIRST_PIPE_INSTANCE` 只保证"名字当时没被占"，不保证后续实例归你；不确权就建其余实例 ⇒ 请求被别人的同名管道接走（**分裂**）。规则：0 号确权、其余等成功。（细节与实测见计划 §13.13；机检：靠评审）
