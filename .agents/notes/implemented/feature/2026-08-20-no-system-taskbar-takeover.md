# Agent Note: 不接管系统任务栏与窗口管理

Status: implemented

## Problem

美化桌面很容易滑向「隐藏原生任务栏、自己实现窗口管理」，这会与原生 Explorer 抢占，带来稳定性与可访问性风险，远超 v1 范围。

## Decision

v1 只叠加悬浮的顶栏与 Dock 两层毛玻璃部件，不隐藏、不接管原生任务栏，也不实现窗口管理；原生桌面仍是底层。

## Alternatives considered

- 隐藏原生任务栏并自绘：体验更统一但风险高、易与系统冲突，否决。
- 提供可选的「接管开关」：增加 P1 复杂度，v1 不做，否决。
- 仅做壁纸层、完全不动任务栏：过于保守，仍保留顶栏与 Dock 以体现美化，采纳当前方案。

## Consequences

v1 稳定性高、与原生共存；代价是顶栏/Dock 可能与原生任务栏在视觉上重叠（已知限制，P1 避让）。
